# 💰 AI-Powered Budget Tracker

A full-stack MERN application that helps users track income and expenses with the power of AI.

## ✨ Features

- 🔐 User authentication with JWT
- 💳 Full transaction management (income & expenses)
- 📊 Visual dashboard with charts and trends
- 🤖 AI auto-categorization of transactions
- 💡 AI financial insights and suggestions
- 🗣️ AI chat assistant for financial advice
- 🌙 Dark/light mode
- 📱 Fully responsive design

## 🛠️ Tech Stack

**Frontend:** React, Vite, Tailwind CSS, shadcn/ui, Recharts  
**Backend:** Node.js, Express.js, MongoDB, Mongoose  
**AI:** Google Gemini API  
**Auth:** JWT, bcrypt  
**Deployment:** Vercel (frontend) + Render (backend) + MongoDB Atlas
